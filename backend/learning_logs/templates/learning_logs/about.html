About Learning Log

Learning Log is a personal journal application for tracking and organizing your learning journey.

Features

  • Create and organize topics
  • Write entries with Markdown support
  • Search across all your entries
  • Track your learning statistics
  • Duplicate entries for templates

Tech Stack

  • Backend: Django 6.0 + Django REST Framework
  • Frontend: Tailwind CSS
  • Editor: Markdown Editor (mdeditor)
  • Database: SQLite
